# Fire or Forecast? Does Wildfire Risk ML Learn Fire Signals or Seasonal Proxies?

Strip climate/season proxies from wildfire classifiers and measure what predictive signal remains.

## This repository is independent
No shared code or data dependencies with the sibling environment papers.

## Quickstart
```bash
pip install numpy pandas scikit-learn matplotlib
jupyter notebook notebook/fire-or-forecast-proxy-strip.ipynb
```

Or open the notebook on Kaggle and Run All.
